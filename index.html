MCP 多智能体协同平台

从圈选目标到个性化营销的一站式体验

结合数据仓库、触达系统与营销策略专家，帮助市场团队快速圈选目标人群、洞察画像并生成个性化营销方案。

🎯 圈选目标人群

Agent 1 负责根据业务目标筛选核心用户，并将结果写入数据仓库。

🧠 人群画像分析

Agent 2 挖掘用户需求与内容偏好，生成可执行的细分画像。

💡 个性化营销策略

Agent 3 结合画像输出触达节奏、内容建议与渠道组合。

多智能体协同流程

Agent 1

人群筛选定义

  • 输入业务目标、地域、行为标签
  • 输出可触达用户清单
  • 写入数据仓库 (MCP)

Agent 2

画像洞察分析

  • 计算资产价值与兴趣图谱
  • 生成内容主题、痛点、KPI
  • 同步至触达系统

Agent 3

营销策略编排

  • 选择渠道组合（短信、邮件、社媒等）
  • 定制话术、优惠与触达节奏
  • 输出个性化营销方案
